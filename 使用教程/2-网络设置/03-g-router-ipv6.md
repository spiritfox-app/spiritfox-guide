# 家里的路由器怎么打开 IPv6

打开 IPv6 不会改变运营商给你的 IPv4 地址，外部网络（WAN）那一页保持原样。只改路由器里「IPv6」这一页，大约五分钟。

## 先放心：只动一个地方
- **IPv4 不变。** 运营商给你的 IPv4 地址、宽带账号和拨号方式都保持原样，也不用找运营商换 IP。
- **IPv6 是另加的一条路。** 打开后，路由器通过原来的宽带连接向运营商多要一组 IPv6 地址，再分给家里每台设备。两种地址同时用，原来能上的网站照常能上。

| 设置页 | 要不要动 |
|---|---|
| 无线网络（Wi‑Fi 名称和密码） | 不动 |
| 外部网络 / WAN / 上网设置（宽带账号、IPv4） | 不动 |
| IPv6 | 只改这一页 |

## 第零步：先测，可能已经有了
很多新的光猫和路由器出厂就开好了 IPv6。
1. 手机先断开 SpiritFox 应用的连接。
2. 连着家里 Wi‑Fi，用浏览器打开 `test-ipv6.com`（英文页面）。
3. 显示你的 IPv6 地址、分数 **10/10**：已经有了，什么都不用改。显示 **No IPv6 address detected**、分数 **0/10**：往下做。

## 第一步：登录路由器，找到 IPv6 页面
1. 准备好管理地址和密码，一般印在路由器背面或底部的标签上。
2. 用连着这个 Wi‑Fi 的手机或电脑，在浏览器里输入管理地址并登录。
3. 在菜单里找「IPv6」，常见在「高级设置」「进阶设置」或「网络设置」下面。
4. **先截一张图**，记下原来的样子，想恢复时照着改回去。

在你点「保存」或「应用」之前，页面上的改动都不会生效。

## 第二步：连接类型选 Native
在「连接类型」里选 **Native**（有的路由器叫「原生」或「自动」）。
- **路由器自己拨号上网**（当初在路由器里填过宽带账号密码）：选 Native。
- **路由器插在光猫后面，宽带账号在光猫里**：也先选 Native。保存后测一次，还没有 IPv6，再改成 **Passthrough**（也叫「透传」或「直通」）试一次。
- 下拉列表里的各种隧道方式是特殊网络用的，不用管。

选好后，页面下方通常会自动填好几项，**保持默认**。以华硕为例：
- 连接接口：PPP（宽带拨号时显示这个）
- DHCP-PD：启用
- 自动配置设置：Stateless
- 自动连接到 DNS 服务器：启用
- 路由器通告（Router Advertisement）：启用

有「IPv6 防火墙」的，保持开启。

## 第三步：保存
点「保存」或「应用」，点一次就够。路由器会重新连一下网络，等半分钟到一分钟。有的路由器要重启才生效。

想恢复：回到 IPv6 页面，把连接类型改回原来的（一般是「关闭」或 Disable），再点应用，就和改之前一样。

## 第四步：验证
1. 手机断开 SpiritFox 应用的连接。
2. 用家里 Wi‑Fi 打开 `test-ipv6.com`。显示有 IPv6 地址，就成功了。再连上应用，「自动选择」会走 IPv6 线路。

**还是没有 IPv6：**
1. 把手机 Wi‑Fi 关掉再打开，再测一次。
2. 看路由器有没有从宽带拿到 IPv6：华硕在「系统记录 → IPv6」看「WAN IPv6 Address」；其他牌子在状态页看外部网络（WAN）的 IPv6 地址。
3. 这一行是空的：路由器已经设好了，是宽带这边还没给。打宽带客服电话，说「想开通宽带的 IPv6，并且给路由器分配 IPv6 前缀」，他们通常可以远程开好，也可以预约上门。
4. 宽带暂时不提供 IPv6：路由器的设置保持原样，不用改回去，以后开通了会自动用上。在那之前，应用会自动走 IPv4 备用线路。

## 常见牌子在哪里
| 路由器 | IPv6 在哪里 |
|---|---|
| 华硕（ASUS） | 进阶设置 → IPv6 → 连接类型从 Disable 改成 Native → 应用本页面设置 |
| 小米 | 米家 App → 网络设置 → IPv6 网络设置；或管理页 → 常用设置 → 上网设置 → IPv6，选「自动配置」 |
| 华为 | 智慧生活 App → 网络设置 → IPv6；或管理页 → 更多功能 → 网络设置 → IPv6，打开开关 |
| TP-Link | 高级设置 → 网络参数 → IPv6（有的型号在 Internet → IPv6），打开后选自动 |
| 新华三（H3C） | 更多 → 接口管理 → IPv6 设置（有的型号要先切到专业模式） |

同一个牌子不同型号，菜单名字可能略有不同。找带「IPv6」字样的那一项就对了。

## 常见问题
<details><summary>会不会把家里的网弄断？</summary>

不会。只改 IPv6 这一页，IPv4 上网不受影响。保存时路由器会重新连一下，几十秒内恢复。

</details>

<details><summary>小区宽带、物业宽带也能开吗？</summary>

各地情况不一样。按上面的步骤试一遍，还没有就问一下宽带服务方。在那之前，应用会自动走 IPv4 备用线路。

</details>
