# 梯子连不上怎么办？翻墙排错指南

梯子突然连不上、显示已连接却打不开网页、晚上变慢、换了手机不会导入……这里把最常见的问题和处理办法按顺序列出来。大多数问题按下面几步走一遍就能解决。

> 本指南由 [SpiritFox](https://spiritfox.app/zh/) 整理，内容来自官网帮助页。通用的排查思路对大多数客户端都适用。

## 先做这三步

1. **更新订阅**：在客户端里点一下「更新订阅」或「刷新主机列表」。服务端换了主机，不更新就连不上新的。
2. **切一下网络**：在 Wi‑Fi 和手机流量之间切一次，或者开关一次飞行模式。
3. **重启客户端**：先正常断开，再退出，再打开。

还不行，再往下看。

## 显示已连接，但什么都打不开

- 先看账号：流量是不是用完了，套餐是不是到期了。
- 都正常的话，更新主机列表，确认设备时间设成「自动」，再重启客户端。
- 看一眼服务状态页，确认是不是服务那边出了问题。

## 只有一个网站打不开，其他都正常

设备可能记住了这个网站的错误地址。重启客户端，然后开关一次飞行模式（手机）或重启电脑。安卓手机还要关闭「私人 DNS」。也可以用浏览器的无痕窗口再试一次。

## 手机流量能用，一连某个 Wi‑Fi 就全部测不出延迟

很可能是这个 Wi‑Fi 没有 IPv6。在路由器设置里打开 IPv6 再试。客户端保持「自动选择」，没有 IPv6 时会自动换到备用入口。

## 应该选哪台主机

保持「自动选择」。客户端会定时测每台主机的延迟，自动连上最快的一台；正在用的那台出了问题也会自己换。只有对机房位置有要求，或者某台一直连不上时，才需要手动选。

延迟数字最低的那台不一定最好用。晚高峰挑两三台常用的，各刷一下视频和网页，哪台稳就先用它，过几天再比一次。

## 晚上会变慢

晚上用的人多。保持「自动选择」，客户端会定时重新测速，换到当时更快的一台。一直慢的话，在客户端里手动重新测一次延迟。

## 关掉客户端后，电脑上不了网了

客户端关闭时可能没有恢复网络设置。重新打开客户端，先正常断开连接，再退出。还不行就重启电脑。

## 客户端切到后台，手机就断开了

手机的省电设置会停掉后台应用。在电池设置里允许这个客户端在后台运行。

## 家里的打印机或其他设备连不上了

访问家里的设备应该直连，不经过梯子。使用分流规则让本地地址保持直连即可。

## 导入了订阅，却看不到主机

用和你的客户端对应的导入方式（格式要对），把客户端更新到最新版本，再刷新主机列表。

## 换了新手机

不用重新注册。登录账号，把订阅重新导入一次就能接着用。

## 换梯子时的小经验

新订阅先别删旧的。两个都导进客户端，白天和晚上各测一次常用的网站，晚高峰也顺，再把旧的停掉。

## 怀疑订阅链接泄露了

先修改账号密码，再重置订阅链接。旧链接会立即失效，然后在自己的每台设备上导入新链接。
