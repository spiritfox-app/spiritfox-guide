# 三步用起来

装一个应用，导入一次，就能用。手机、平板、电脑都可以，台数不限。

## 第一步：装应用

每种设备用哪个应用，按下表装。下载地址和每个文件的指纹（SHA-256）都在控制台「下载」页。

| 设备 | 用这个应用 | 从哪里装 |
|---|---|---|
| iPhone、iPad | sing-box MT | App Store。国区搜不到，要用海外地区的 Apple ID，做法见「iPhone 和 iPad 怎么装上应用」 |
| 安卓手机、平板 | sing-box，或 FlClash | 「下载」页 |
| Mac | Clash Verge Rev | 「下载」页。分 Apple 芯片和 Intel 芯片两种，别下错 |
| Windows | Clash Verge Rev | 「下载」页 |
| Linux 桌面 | Clash Verge Rev（64 位） | 「下载」页，有 deb 和 rpm 两种安装包 |

这些应用都是开源的，我们只推荐实测能正常用的版本。只从控制台的链接或官方应用商店下载：假冒的热门应用是盗号的常见手段。

## 第二步：导入

在要用的那台设备上打开控制台「订阅地址」页，点你这个应用的导入按钮。应用会自动收到全部节点。

- 电脑上看控制台、手机上导入：用手机应用扫控制台里的二维码。
- **不要用微信、QQ 这类聊天软件把订阅地址发给自己。** 原因见「订阅地址就是你的钥匙」。

## 第三步：连接

打开应用，选「自动选择」，点连接。

「自动选择」会测出此刻最快的节点，优先走 IPv6。你所在的网络没有 IPv6 时，它会在大约 1 分钟内自动改走 IPv4 备用线路，不用你动手。为什么这样设计，见「IPv6 优先：我们的线路为什么这样设计」。

## 用在多台设备上

- **流量共用。** 所有设备的流量加在一起，算在同一个套餐里，在控制台「流量明细」随时能看。
- **每台设备各选各的节点。** 手机和电脑可以连不同的节点，互不影响。
- **加设备、换手机。** 在新设备上重复第一步和第二步就行，旧设备不用先退出。
- **只能你本人用。** 台数不限，但不能和别人合用、转卖或公开分享。同时在线的设备明显多于一个人的正常数量时，我们会发邮件提醒你；都是你自己的设备，就不用管。
