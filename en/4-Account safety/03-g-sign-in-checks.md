# Why big websites keep asking you to prove you're human

When using sites like Google or ChatGPT, you may see:
- a CAPTCHA, or an "I'm not a robot" box;
- a confirmation code by email or text, or a "new sign-in" alert;
- some features temporarily unavailable until time passes or you verify.

These are the site's security checks to stop account theft and bulk sign-ups. They don't mean something is wrong with your account.

## How a site decides to check you
It compares this sign-in with your usual habits; the bigger the difference, the more likely it asks for another step:
- **Device:** a phone, computer or browser it hasn't seen, or browser history just cleared.
- **Network:** a changed network address, or many people using the same address at once.
- **Behaviour:** several wrong passwords in a short time, or actions faster than a person's.

## What to do
1. Complete it as the page asks. After that, the site usually remembers this device and network.
2. Enter confirmation codes only on the site's own page and never tell anyone.
3. If it keeps failing, stop for a while and try later. Repeated attempts make the site more suspicious.
4. If the check box won't load or keeps spinning, turn off ad- or script-blocking browser extensions, or try another browser.
5. If the account is temporarily restricted, use the site's own recovery or appeal process.

**Watch out for fake checks.** Real checks only ask you to tick, click pictures, type a code or confirm by email. Anything asking you to download software, install an extension or copy a command into your computer is a scam; close it at once.

## How to see them less
- **For sites like these, pick one server by hand.** Auto select moves between servers, so the address the site sees changes too; picking one keeps it steady. Switch back to Auto select if that server stops responding.
- **Stay signed in on devices you use often**; don't keep signing out or clearing these sites' data.
- **Turn on two-step verification for important accounts**, and keep the backup codes so a new phone doesn't lock you out.
- **Don't share accounts.** Different people signing in to one account from different places is the surest way to trigger checks.
