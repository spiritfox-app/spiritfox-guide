# Apps and connecting

<details><summary>Imported the subscription but no servers show?</summary>

Use the import button for your app on the Subscription link page so the format is right. Then update the app to the latest version and update the subscription once.

</details>

<details><summary>How do I refresh the server list?</summary>

Update (refresh) the subscription in the app, or tap import again on the console's Subscription link page; it has the same effect. The console can't refresh the app for you.

</details>

<details><summary>Which server should I choose?</summary>

Keep Auto select on. It tests each server's latency regularly, uses the fastest, and switches if the current one has trouble. Pick by hand only if you need a particular region; to go back, choose Auto select again. The TCP or UDP at the end of a server name is the connection type; if one is slow, switch to the other.

</details>

<details><summary>It says connected, but nothing opens?</summary>

Check Overview first: has your traffic run out or your plan expired? If not, go through 「Can't connect or slow: check in this order」.

</details>

<details><summary>My antivirus warns about the app?</summary>

Apps that manage network connections sometimes trigger false alarms. Install only from the console's Download page and check the file fingerprint. If the warning persists, ask us in Tickets before allowing it.

</details>

<details><summary>Mac says the app "is damaged" or "from an unidentified developer"?</summary>

This is macOS's standard check for apps outside the App Store. Follow the Mac steps on the console's Download page. Don't turn off your Mac's security settings to get around it.

</details>

<details><summary>My phone shows a "connection request" to allow?</summary>

That's normal. The phone asks once the first time the app connects; tap "Allow". Only one app of this kind can run at a time, so close the others first.

</details>

<details><summary>The phone disconnects when the app goes to the background?</summary>

Battery saving can stop background apps. In your phone's battery settings, allow this app to run in the background.

</details>

<details><summary>After closing the app, my computer has no internet?</summary>

The app didn't restore your network settings when it quit. Open the app, disconnect normally, then quit. If that doesn't help, restart the computer.

</details>

<details><summary>Can't reach my home printer or NAS?</summary>

Devices at home should connect directly. Keep the app in Rule mode; the subscription's rules send home network addresses direct. See 「Rule mode: what goes direct and what goes through our lines」.

</details>
