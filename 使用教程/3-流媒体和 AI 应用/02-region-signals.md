# 服务方怎么判断你在哪里

视频和 AI 服务判断你的地区，不只看你连的节点。下面是九种常见依据，以及连上我们的节点后哪些会变、哪些不会。显示的地区和你选的节点对不上时，按这张表找原因。

各服务不会公开全部做法。这里只写有官方说明或技术标准依据的内容。

## 一张表看清
| 依据 | 从哪里来 | 连上节点后会变吗 |
|---|---|---|
| 网络地址（IP） | 你连进来的地址 | **会**：服务看到的是节点的地址 |
| 账号记录 | 注册、登录和使用记录 | 只有新记下的地址会变，以前的记录不会 |
| 手机号 | 注册时验证的号码 | 不会 |
| 付款方式 | 银行卡发卡国家、账单地址、币种 | 不会 |
| 应用商店地区 | 商店账户登记的国家或地区 | 不会 |
| 设备定位 | 卫星、Wi‑Fi、基站（要你授权） | 不会 |
| 域名查询（DNS） | 设备把网址换成地址的那一步 | 看设置，见第 7 条 |
| 浏览器和设备指纹 | 浏览器和设备的各种特征 | 不会 |
| 时区和语言 | 你的系统设置 | 不会 |

## 1. 网络地址（IP）
服务方最先看、最常用的一项。网络地址由地区性登记机构层层分配给运营商和机房；专门的定位数据公司把登记信息和运营商公布的数据（技术标准 RFC 8805）合在一起，做成数据库卖给网站。

- **能准到哪：** 一家主要的定位数据公司（MaxMind）公开的估计是，国家一级约 99.8%；城市一级差得多，美国境内城市（50 公里内）约 66%。他们也写明，这类数据不可能精确到某一户人家。
- **地址类型：** 有的服务会识别 VPN 和代理的地址，比如 Netflix。
- Google 写明，位置信息可以来自 IP 地址这类实时信号，IP 地址大致按地理位置划分。原文：`policies.google.com/technologies/location-data`

## 2. 账号记录
单次连接看的是「现在」，账号记录看的是「一直以来」：注册时的国家、每次登录的时间、设备和地址、常用的时间和地点。
- **YouTube Premium**：会员应主要在注册的国家使用；谎报所在地（例如使用 VPN）或试图绕过限制，订阅可能被取消。原文：`support.google.com/youtube/answer/6307365`
- **Netflix**：家庭共享以「家庭」为单位，指在你主要观看 Netflix 的地方连上网络的一组设备。原文：`help.netflix.com/en/node/123277`

所以常用的服务，固定在同一地区的节点、同一台设备上用，记录更连贯。

## 3. 手机号
号码开头的国家代码（+86、+81）直接说明号码是哪国发的，也能看出是不是网络电话号码。
- **Claude**：新用户必须验证手机号，没有办法跳过；号码须来自支持的地区，不接受网络电话号码。原文：`support.claude.com/en/articles/8287232`

## 4. 付款方式和账单地址
银行卡号开头几位按国际标准（ISO/IEC 7812）分配给发卡机构，商家能看出卡是哪国哪家银行发的；账单地址会和卡上登记的核对；扣款币种也说明了国家。这些信息只在你和服务方之间传递，不经过我们。

## 5. 应用商店地区
能下载哪些 App，看的是商店账户登记的地区，不看你连哪个节点。换节点不会改变它，已经装好的 App 照常用。
- **Apple**：换国家或地区前，要先花完余额、取消订阅并等到期，可能还要新地区的付款方式。原文：`support.apple.com/en-us/118283`
- **Google Play**：要身在新的国家或地区、有当地付款方式；改过一次后至少 90 天才能再改。原文：`support.google.com/googleplay/answer/7431675`

## 6. 设备定位
手机和电脑自己就能估算位置，往往比网络地址准得多。Google 写明，安卓设备用 GPS、传感器、移动网络和 Wi‑Fi 信号估算位置。周围 Wi‑Fi 热点各有固定的硬件编号，室内也能定位。

App 读取定位需要你在系统里授权，网页读取浏览器会先弹窗问你。拒绝后，App 拿不到精确位置，但仍看得到网络地址、时区和语言。

## 7. 域名查询（DNS）
很多大网站会按查询来源返回离你近的服务器地址。技术标准 RFC 7871 写明，权威域名服务器会根据用户被感知到的网络位置返回不同结果，替你查询的服务器还可能把「查询来自哪个网络」的前一部分转告对方。

连上我们的线路后，境外网址的查询经节点在境外进行，和节点地区一致，见「网址打不开：DNS 劫持、污染和清缓存」。如果你在浏览器或设备里手动设过 DNS，查询可能绕开线路，网页内容和域名查询就会透露出两个不同的地区，表现为打开变慢或显示的地区不对。

## 8. 浏览器和设备指纹
制定网页标准的 W3C 定义：指纹是网站通过配置和其他可观察到的特征，识别或再次识别某个访问者、浏览器或设备的能力。单看「屏幕 1920×1080」很多人一样，几十项拼在一起就可能只剩你这一台。
- **被动指纹**：只看你发过去的请求，包括请求头（浏览器版本、系统、偏好语言）和 IP 地址。
- **主动指纹**：网页运行脚本读取窗口大小、字体、绘图细节等。

W3C 写明，清除 Cookie 或使用 VPN 都不能阻止这种关联，指纹通常无法清除或重置。原文：`w3.org/TR/fingerprinting-guidance/`。各服务是否用指纹判断地区，一般不公开。

## 9. 时区和语言
不需要任何权限，打开网页就能读到：系统时区（格式类似 `Asia/Shanghai`）、偏好语言、日期和货币格式。Google 写明，浏览器时区、页面语言等信息可能被用来估计你所在的国家（用于广告）。很多人在国外也用中文、用北京时间，所以这几项通常和其他依据一起看。

## 网页视频通话会透露真实地址吗
浏览器的实时音视频功能（WebRTC，视频会议网页常用）需要知道网络地址。技术标准 RFC 8828 写明，网页应用能借此了解到并未暴露在互联网上的地址，在某些网络设置下还可能看到你本地运营商的公网地址。

标准原文都在 `www.rfc-editor.org/rfc/rfc` 加编号，例如 `rfc7871`。
